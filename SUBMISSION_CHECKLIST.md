# Issue #51 Submission Checklist

Use this file as the final PR/Discussion hand-off. The source package is
submission-ready, but benchmark numbers must be regenerated when the
checkpoint, dataset split, or target SDK changes.

## Required evidence

- [ ] Fine-tuned EsMoE-N checkpoint and dataset YAML are recorded.
- [ ] `scripts/export_models.py` produced a checker-valid, onnxsim-simplified
      static ONNX file and an NCNN param/bin pair with a successful load and
      extractor smoke test.
- [ ] The same ordered validation list contains at least 500 images.
- [ ] `scripts/eval_map.py` reports PyTorch versus each FP32 backend with the
      same `conf=0.001`, `iou=0.70`, multi-label, class map, and max-det=300,
      and uses `--max-abs-delta-pct 0.5` to enforce the FP32 budget when a
      reference JSON is supplied.
- [ ] INT8 uses at least 300 training images, records the calibration manifest,
      and reports mAP50-95 error below 1% if the optional gate is claimed.
- [ ] `scripts/mnn_parity.py` (or an equivalent raw-tensor check) records shape,
      finite-value, max/mean error, and a debug snapshot for any mismatch.
      `export_models.py` intentionally marks MNN as converter-checked, not
      runtime-acceptance-ready, until this item is complete.
- [ ] Every acceptance image has both a label file and a prediction file; raw
      VisDrone annotations use `--label-format visdrone` so ignored categories
      cannot be counted as detections.
- [ ] Timing CSVs include preprocessing, inference, postprocessing, total,
      P50/P95/P99, and FPS for every backend/platform.
- [ ] CMake configure/build logs are attached for two target platforms.

## Commands

```bash
python scripts/export_models.py --model runs/issue51/esmoe_n_visdrone/weights/best.pt \
  --out-dir exports --formats onnx ncnn mnn --imgsz 640 --opset 12

python scripts/quantize_int8.py --fp32 exports/best.onnx \
  --train /data/VisDrone/images/train --n-calib 500 \
  --out exports/best_int8.onnx

./cpp/build/yolomaster_edge --model exports/best.onnx \
  --source /data/VisDrone/images/val --acceptance --warmup 5 \
  --save-txt artifacts/onnx_txt --csv artifacts/onnx_timing.csv --no-save

python scripts/eval_map.py --preds artifacts/onnx_txt \
  --images /data/VisDrone/images/val --labels /data/VisDrone/labels/val \
  --classes visdrone --label-format visdrone \
  --reference-json artifacts/pytorch_map.json --max-abs-delta-pct 0.5 \
  --json artifacts/onnx_map.json
```

Use `--label-format visdrone` for raw VisDrone annotation rows, or
`--reference-json artifacts/pytorch_map.json` to emit the relative mAP delta.
The optional `--max-abs-delta-pct` gate returns non-zero when the absolute value
of the relative delta exceeds the requested budget (`0.5` for FP32, `1.0` for INT8);
it has no effect on the default smoke workflow when omitted.
